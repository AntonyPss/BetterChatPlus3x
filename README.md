# Better Chat+++

Better Chat+++ v1.3.0 is a Minecraft Bedrock resource pack that expands the in-game chat with utility controls and a resizable chat/sidebar layout.

## Features

- Command and player-name autocomplete.
- Previous and next message navigation.
- A toggleable right sidebar containing current coordinates, notes, and a calculator; the chat resizes to the remaining space.
- Coordinate copy and paste controls.
- Basic integer arithmetic: addition, subtraction, multiplication, and division.
- Chat settings for mute and text-to-speech options.
- Chat remains usable alongside the sidebar, which can be toggled from the lower chat controls.

Notes are temporary and disappear when leaving the world.

## Installation

1. Import the `BetterChatPlus3x-v1.3.0.mcpack` file by opening it with Minecraft Bedrock.
2. In Minecraft, open **Settings > Global Resources**.
3. Activate **BetterChat+++**.

## Compatibility

The manifest declares Minecraft Bedrock 1.21.0 as the minimum engine version. Custom UI packs can be affected by game updates; test the pack in the target game version before distributing it.
